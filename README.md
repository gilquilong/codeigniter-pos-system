# Basic Point-of-Sale System

This project is a basic four-page Point-of-Sale website created using CodeIgniter 4. It demonstrates how routes, controllers, and views work together.

## Pages

The website contains the following pages:

- Home
- About
- Customer Accounts
- User Accounts

The Customer Accounts and User Accounts pages use static PHP arrays as temporary data sources. No database is used in this version of the project.

## Customer Information

The Customer Accounts page displays:

- Full name
- Email address
- Phone number

## User Information

The User Accounts page displays:

- Username
- Full name
- Role

## Technologies Used

- PHP 8.2
- CodeIgniter 4
- HTML
- CSS
- Composer
